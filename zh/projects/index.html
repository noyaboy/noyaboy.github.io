En
  • 軌跡重建加速器 TSMC 28nm 下線 (陽明交大 平行計算系統實驗室，2026/07 - 至今) 將軌跡重建加速器從 RTL 一路帶到 TSMC 28nm 下線成為晶片。這個設計源自我在論文中以 traccc 進行的設計空間探索。在 GPU 上，事件層級融合消除了主機端的啟動瓶頸，卻暴露出受限於工作量、又因資料相依的 warp divergence 而效能低落的核心函式。AMD Versal V80 的空間運算陣列消除了 divergence，但有限的繞線資源限制了核心數，組合式卡爾曼濾波器的回授迴路也限制了迭代吞吐量。Tenstorrent 這類 MIMD 多核心架構同樣避開了 divergence，代價則是運算密度降低。
  • AI Agent 自動化流程 (晶心科技，2026/07 - 至今) 以客製化的 SKILL.md 檔案自動化團隊工作流程，涵蓋心智模型萃取、差距分析、執行與知識管理四個階段。 投影片
  • Regfile RTL/C 程式碼自動生成流程 (晶心科技，2024/11 - 至今) 將 CSV 暫存器規格自動編譯成可合成的 Verilog 暫存器檔、C/C++ 標頭檔與文件，確保軟硬體介面一致。2026 年起加入中間表示（IR）最佳化。工具：Perl、Python、Verilog、Shell、Makefile。
  • 雙核心 RISC CPU：UMC 180nm 從 RTL 到簽核 (陽明交大 ICLAB 期末專題，2026/03 - 2026/07) 雙核心 RISC 處理器，在 UMC 180nm 走完完整的 RTL 到 GDSII 流程，包含設計、模擬與形式驗證、合成、時序收斂及佈局繞線。工具：Verilog、VCS、Spyglass、Design Compiler、JasperGold、PrimeTime、Innovus。 GitHub
  • 弱重力透鏡收斂圖的超輕量 HDC-CNN (陽明交大 深度學習期末專題；NeurIPS 2025 FAIR Universe Weak Lensing Uncertainty Challenge，2025/10 - 2025/11) 參數量 0.2M 的混合膨脹卷積 CNN 集成模型，以保序校準做穩健的不確定性量化。工具：Python、PyTorch、TensorFlow。 GitHub
  • 具 Hazard 處理的 RISC-V 五級管線 CPU 核心 (清華大學 ICLAB 期末專題，2023/12 - 2024/01) RV32I 五級管線核心，具備 forwarding、hazard 停頓與雙 bank 指令及資料快取，以 GPDK 45nm 實作。工具：Verilog、VCS、Spyglass、Design Compiler、PrimeTime、Innovus。 GitHub
